# kenbenoit-site

Source for the rebuilt <https://kenbenoit.net> (Hugo + Hugo Blox, hosted on Netlify).

The build is specified in [`docs/build-spec.md`](docs/build-spec.md), which extends Gary King's mysite prompt (<https://gking.harvard.edu/mysite/files/ACADEMIC_SITE_PROMPT.md>).

The site went live on 16 October 2026. The previous site, built from [`kbenoit/kbenoit-hugo-site`](https://github.com/kbenoit/kbenoit-hugo-site), is kept as an archive and as the rollback target. Checks that guard the legacy URLs and search/AI visibility are described in [`_automation/README.md`](_automation/README.md).
